Perguntas Frequentes (FAQ)

Como funciona a conversão para Ternário Balanceado?
A conversão utiliza um algoritmo de complexidade O(n) que ajusta cada dígito standard (0, 1, 2) para a forma balanceada (-1, 0, 1), aplicando um transporte ('carry') sempre que o valor excede a metade da base (1.5).
O que é Heptavintimal (Base 27)?
Heptavintimal é um sistema de base 27. Este software utiliza o alfabeto de Jones (0-9, A-Z excluindo I, J, L, O, Q, S, U, W, Y) para representar trios de dígitos ternários (trits) de forma compacta e sem ambiguidades visuais.
Por que usar a Ponte Nonária?
A Ponte Nonária (via Base 9) é o caminho mais eficiente para converter entre sistemas decimais e ternários, aproveitando que 9 = 3², permitindo mapeamentos lineares rápidos após uma única conversão quadrática inicial.
